# Start HRMS Session

When `/start` is invoked:

1. Read `hrms-be/README.md`.
2. Read `hrms-be/ROADMAP.md`.
3. Read the latest `hrms-be/progress/session-XX.md`.
4. Inspect relevant `hrms-be` and `hrms-fe` code when needed to verify status.
5. Build an internal understanding of:
   - project architecture
   - implemented features
   - pending features
   - known issues
   - current priorities
   - important technical/configuration decisions
6. Do not modify any files.
7. Do not implement anything.
8. After loading context, briefly report:
   - Current state
   - Completed major features
   - Pending priorities
   - Known issues
   - Latest session

Treat `ROADMAP.md` as the primary status/checklist source, but verify
important claims against the code when necessary.
